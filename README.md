# Traveler Website

A multi-page travel agency website with destinations, tour packages, services, guides, testimonials, blog and contact pages. Customised from a free HTML travel template.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=white)

## Features

- 11 pages: home, about, services, packages, destinations, guides, testimonials, blog, single post, contact
- Responsive Bootstrap layout with SCSS sources
- Carousels and animated sections

## Tech stack

- HTML5, CSS3 / SCSS, Bootstrap
- JavaScript and jQuery plugins

## Getting started

```bash
# no build step: open index.html in a browser, or serve the folder
npx serve .
```
